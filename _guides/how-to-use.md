## Start Here

1. Read the [About](/about/) page to see who this resource is for.
2. Work through the [Units](/units/) in order.
3. Check unfamiliar words in the [Glossary](/glossary/).
4. Use the search icon (top right) to find any topic.

## On Each Unit Page

- The **sidebar** lists all units.
- The **"On this page"** box jumps between sections.
- **Review questions** at the end have hidden answers — try first, then click "Show answers".
